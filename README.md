# Async Scraper

Python scraper using Playwright + BeautifulSoup.

## Features
- Async scraping
- Pagination support
- Export JSON / CSV
- User-agent rotation

## Installation

```bash
git clone https://github.com/yourname/async-scraper.git
cd async-scraper
python -m venv venv
venv\Scripts\activate  # Windows
pip install -r requirements.txt
playwright install
